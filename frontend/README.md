# とくとくタッチ (PointPass) - 来店ポイントシステム

ShinjirouTakata-dev/visitor-points のUI/UXおよびBGM・効果音、操作性を全面的に刷新した来店ポイントシステムです。
WindowsおよびAndroidタブレット・キオスク端末での運用を想定した設計となっています。

---

## 🌟 主な改修・実装機能

1. **待ち受け待機画面 (2ブロック構成・レジ待ち時間訴求)**
   - **左ブロック**: 「レジ待ち時間に、運試し。」の強い訴求 ＋ 設定された営業時間（例: 09:00〜22:00）と連動した「時間帯別参加者数推移グラフ（Recharts）」を常時表示。
   - **右ブロック**: 「本日の参加総数（X名）」および「あなたが本日Y番目！」のリアルタイム順位表示、ワンタッチで開始する「ゲームを始める →」ボタン。

2. **会員バーコード認証 (カメラ読み取り ＆ ソフトウェアテンキー)**
   - カメラ枠内に会員バーコード（JAN / NW-7等）をかざすだけで自動認識。
   - NW-7のスタート/ストップキャラクタ（A〜D等）を自動除去し、純粋な数値ペイロードに正規化してAPI照会。
   - 入力欄タッチ時に画面下部へ大型数値ソフトウェアテンキーを表示（物理キーボードのないタッチパネルでもスムーズに入力可能）。

3. **ミニゲーム3種 (スロット / ルーレット / スクラッチ)**
   - 店頭設定で指定された1等〜5等および参加賞（ハズレ）の確率と1日最大当選本数を厳密に管理する抽選エンジン。

4. **3分割確定アナウンス (日本語AI音声 ＆ WAVファイル差替設計)**
   - ポイント確定時に以下の3パートで順次再生：
     - **パート1**: 「おめでとうございます！」（独自WAVファイル差替対応）
     - **パート2**: 「Xポイント付与です！」（可変値のため日本語AI音声合成）
     - **パート3**: 「ご来店ありがとうございます。」（独自WAVファイル差替対応）
   - 設定画面から個別試聴および一連の通し再生テストが可能。

5. **店舗管理者設定メニュー (暗証番号: 5963)**
   - アプリタイトル名、アプリアイコン文字/カラー、店舗名、営業時間（開始〜終了）のカスタマイズ。
   - 会員名の表示/非表示（個人情報保護対応）切替。
   - ポイント照会API・ポイント訂正APIの各エンドポイントURL、ポート番号、ローカル/本番IP切替、疎通テスト機能。
   - 完了後の自動TOP復帰タイマー（N秒設定）。
   - 100日間自動保有・顧客コード付きトランザクションログ、月次集計、CSVダウンロード機能。
